# Dataset Attribution

Both datasets used in this project are distributed by the **UCI Machine Learning
Repository** and are licensed under the **Creative Commons Attribution 4.0
International (CC BY 4.0)** license. Under CC BY 4.0 you are free to share and
adapt the data for any purpose, provided you give appropriate credit.

## 1. Individual Household Electric Power Consumption *(primary dataset)*

- **Source:** UCI Machine Learning Repository — Individual Household Electric
  Power Consumption Data Set
- **URL:** <https://archive.ics.uci.edu/dataset/235>
- **Direct download:** <https://archive.ics.uci.edu/static/public/235/individual+household+electric+power+consumption.zip>
- **License:** CC BY 4.0
- **Original donors / citation:**

> Georges Hébrail (EDF R&D, LIST, Clamart, France), Alice Bérard (LISIC /
> Université Lille 1), Jean-Marc Temam del Rio (EDF R&D). *Individual Household
> Electric Power Consumption*. UCI Machine Learning Repository (2012).
> DOI: <https://doi.org/10.24432/C58J3R>.

**Attribution statement used in this project:** “This project uses the
‘Individual Household Electric Power Consumption’ dataset by Georges Hébrail,
Alice Bérard and Jean-Marc Temam del Rio, distributed by the UCI Machine
Learning Repository (<https://archive.ics.uci.edu/dataset/235>, DOI
10.24432/C58J3R) under the Creative Commons Attribution 4.0 International
license. The data has been filtered, aggregated and visualized but not altered
at the source-record level.”

**Bundled copy:** `data/raw/household_power_consumption.txt`
(2,075,259 rows × 9 columns, Dec 2006 – Nov 2010).

## 2. Online Retail *(secondary dataset)*

- **Source:** UCI Machine Learning Repository — Online Retail Data Set
- **URL:** <https://archive.ics.uci.edu/dataset/352>
- **Direct download:** <https://archive.ics.uci.edu/static/public/352/online+retail.zip>
- **License:** CC BY 4.0
- **Original donor / citation:**

> Daqing Chen, Sai Liang Sain, and Kun Guo, *Online Retail*. UCI Machine
> Learning Repository (2015). DOI: <https://doi.org/10.24432/C5BW32>.
> Original publication: Chen, D., Sain, S. L., & Guo, K. (2012). Data mining for
> the online retail industry: A case study of RFM model-based customer
> segmentation using data mining. *Journal of Database Marketing & Customer
> Strategy Management*, 19(3), 197–208.

**Attribution statement used in this project:** “This project uses the ‘Online
Retail’ dataset donated by Daqing Chen, Sai Liang Sain and Kun Guo, distributed
by the UCI Machine Learning Repository (<https://archive.ics.uci.edu/dataset/352>,
DOI 10.24432/C5BW32) under the Creative Commons Attribution 4.0 International
license.”

**Bundled copy:** `data/raw/Online Retail.xlsx` (541,909 rows × 8 columns,
UK transactions 2010–2011).
